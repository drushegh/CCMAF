# Contributing

First — thank you for looking. Here's how this repository works.

## This is a published mirror

CCMAF is developed in private maintenance repositories and **republished here as
clean releases**. That shapes how contribution works:

- ✅ **Use it freely.** Clone, copy, fork, adapt — it's [MIT](LICENSE). That's the point.
- 💬 **Feedback is genuinely welcome.** Open an
  [Issue](https://github.com/drushegh/CCMAF/issues) or start a
  [Discussion](https://github.com/drushegh/CCMAF/discussions). Bug reports, ideas,
  "this confused me" notes, and "here's what I'd change" all help and are read.
- 🚫 **Pull requests are not merged here.** Because every change flows from the
  upstream maintenance repos and is republished, an inbound PR against this mirror
  can't be accepted — so PRs are **automatically closed** with a pointer back here.
  This isn't a brush-off: the *idea* behind your PR is very wanted. Please open an
  Issue describing the change (paste your diff or a summary) and it can be carried
  upstream with credit.

## If you adopted the framework

As you work, your agents record improvement ideas in your project's own
`.claude/FRAMEWORK-SUGGESTIONS.md`. That file is local to you — nothing is ever
transmitted automatically. To send an idea back, paste the entry into an
[Issue](https://github.com/drushegh/CCMAF/issues/new/choose). The more context
(what happened, what you'd expect), the better.

## Security

Found something sensitive? Please **don't** open a public Issue for it. Use GitHub's
[private vulnerability reporting](https://github.com/drushegh/CCMAF/security/advisories/new)
instead.

Thanks for helping make it better. 🙏

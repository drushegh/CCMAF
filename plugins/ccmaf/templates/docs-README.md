# docs/ — project documentation tree

Deposit supplementary material HERE as you work — research, inspiration,
images, diagrams — don't leave it only in chat. The Console (if enabled)
surfaces this tree under its Docs tab.

- `inspiration/` — references, moodboards, prior art
- `research/` — findings, comparisons, cited evidence
- `images/` — screenshots, renders, generated assets
- `diagrams/` — architecture and flow diagrams (sources + exports)
- `code-conventions.md` — this project's coding conventions (yours to grow)
- `architecture.md` — module map + boundaries (yours to grow)
